## 第1节 均衡国民收入决定理论

总供给如何决定于总需求？

---

### 国民收入核算方法

**总产出、总收入、总支出的定义：**

- **总产出**：就是GDP，即是一国或一定地区在一定时间内运用生产要素所生产的全部最终产品（物品和劳务）的市场价值
- **总收入**：生产GDP的要素所有者的全部收入（工资、利息、租金、正常利润）
- **总支出**：全社会购买最终产品GDP的总支出

---

### 国民收入核算思想

**循环流量图复习：总产出、总收入、总支出的关系**

1. **（总）产出=（总）收入**
   
   产出是生产要素共同创造的，产出值自然要转化为要素提供者的收入。一个企业的产出总等于收入，一个国家的总产出也必然等于总收入。

2. **（总）产出=（总）支出**
   
   产出是为购买者而生产的，自然最终产品的销售收入，就是最终产品购买者的支出。
   
   具体地说，总产出=市场购买总支出+存货总投资（支出）
   
   用公式表示即为：**总收入=总产出=总支出**

---

### 国民收入核算思想

认识总"收入=总产出=总支出"这一公式对于弄清如何核算GDP有重大意义。

1. 从理论上说，GDP=∑P~i~Q~i~。如果用（Q~1~, Q~2~, ……Q~i~）代表各种最终产品的数量，用（P~1~, P~2~, ……P~i~）代表各种最终产品的价格，则Q~1~P~1~+Q~2~P~2~+……+Q~i~P~i~=GDP。但实际上，这种计算不可能。

2. 通过"收入=总产出=总支出"这一公式，我们就可以通过其它比较简单的方法（支出法、收入法）来计算清楚GDP。

---

### 支出法（Expenditure Approach）

又称产品支出法、产品流动法、最终产品法。

把一年内购买的各种最终产品支出加总起来，计算出该年内生产出来的产品和劳务的市场价值。

$$GDP = 消费 + 投资 + 政府购买 + 净出口$$

$$GDP = C + I + G + (X - M)$$

**概念理解**：消费和投资。

---

### 收入法（Income Approach）

又称所得法、要素支付法。

把生产过程中各种生产要素所得到的收入，即工资、利润、利息和租金相加起来。

包括：
1. 工资、利息和租金等生产报酬
2. 非公司企业主收入
3. 公司税前利润
4. 企业转移支付及企业间接税
5. 资本折旧

---

### 收入法（Income Approach）

收入法是从生产要素收入的角度，把生产要素在生产中所得到的各种收入相加来计算的GDP，即把劳动所得到的工资、土地所有者得到的地租、资本所得到的利息以及企业家才能得到的利润相加来计算GDP。

但不能仅从字面上狭隘理解成只包括工资、地租、利息、企业家才能四个项目。

严格地说，最终产品市场价值除了生产要素构成的成本，还有间接税、折旧、公司未分配的利润等内容。

---

### 收入法（Income Approach）

用收入法核算GDP应包括以下项目：

$$GDP = 工资 + 利息 + 利润 + 租金 + 间接税和企业转移支付 + 折旧$$

**间接税与直接税说明**：

1. **间接税**：对商品和劳务征收的税，特点是税负不由纳税人直接承担，可以转嫁出去。
2. **直接税**：对财产和收入征收的税，特点是税负不能转嫁，由纳税人直接承担。

---

### 部门法/生产法（Sector Approach）

部门法核算GDP是按提供产品和劳务的各部门的产值来计算。

用生产法核算GDP，是指按提供物质产品与劳务的各个部门的新增产值来计算国内生产总值。生产法又叫部门法。

运用这种方法进行计算时，各生产部门要把使用的中间产品的产值扣除，只计算所增加的价值。商业和服务等部门也按增值法计算。卫生、教育、行政、家庭服务等部门无法计算其增值，就按工资收入来计算其服务的价值。

---

### 三种核算方法的关系

**最终产品的价值的形成过程**：

- 所有企业资产增值的总和 → 生产法
- 最终产品流向：
  - 居民（消费）
  - 企业（投资）
  - 政府（购买）
  - 国外（净出口）
  
→ 支出法

- 收入渊源：
  - 劳动工资
  - 资本利息
  - 土地租金
  - 企业家利润
  
→ 收入法

---

### 三种核算GDP的方法的比较

1. **生产法**最准确。但这种方法的可操作性不强。
2. **支出法**最具可操作性，但不尽准确。
3. **收入法**介乎于一、二种方法之间。

常用的是支出法与生产法。尤其是支出法。现在各国一般都把它作为核算国民收入最基本的方法。

## 宏观经济循环

**宏观经济循环图：**

- 企业储蓄 ↔ 货币市场
- 家庭 ↔ 政府 ↔ 企业
- 私人储蓄 ↔ 借贷
- 生产要素市场 ↔ 产品与服务市场
- 家庭收入 ↔ 生产要素支付 ↔ 消费
- 企业收入 ↔ 政府购买 ↔ 公共产品与服务 ↔ 税收

**关键关系**：总收入 ↔ 总需求/总支出 ↔ 总供给/总产出

## 两部门经济

**两部门经济（Two Sector Economy）假设**：

由厂商和居民户这两种经济单位所组成的经济。没有折旧，没有间接税收，没有政府支出，没有进出口贸易，是一种最简单的经济。

---

### 两部门经济循环

**收入流量循环模型图**：从该图中可以看出，只要家户部门把所得到的所有收入都用于购买厂商的产品与劳务，这个循环就可以以原有的规模一直维持下去。

---

### 两部门经济条件下的国民收入构成

**从支出角度看**，由于把企业库存作为存货投资，即：

国内生产总值 ≡ 消费支出 + 投资支出 ≡ 消费 + 投资

即：$$Y = C + I$$

**从收入角度看**，国内生产总值就等于总收入，而总收入要么消费，要么储蓄：

国民收入 ≡ 产值的总和 ≡ 各种生产要素的收入总和 ≡ 工资 + 利息 + 租金 + 利润 ≡ 消费 + 储蓄

即：$$Y = C + S$$

---

### 储蓄——投资恒等式

由 $C + I ≡ Y ≡ C + S$，可以得到：

$$I ≡ S$$

即：**投资 = 储蓄**

**对储蓄——投资恒等式的说明**：

1. 恒等式是在假设的两部门经济条件下，根据储蓄与投资的定义得出的，而不是根据经济运行实际得出的。
2. 恒等式是指整个经济，而不是针对某个人或某个企业而言。
3. 恒等式是事后实际发生的国民收入均衡；是按照当年市场价格计算的。

---

## 三部门经济

**三部门经济（Three Sector Economy）**是指由厂商、居民户与政府这三种经济单位所组成的经济。在这种经济中，政府通过税收与居民户及厂商发生联系。

---

### 三部门经济：储蓄——投资恒等式

**从支出（总需求）看**：

国内生产总值 ≡ 消费支出 + 投资支出 + 政府支出 ≡ 消费 + 投资 + 政府购买

即：$$Y = C + I + G$$

**从收入（总供给）看**：

国民收入 ≡ 各种生产要素的收入总和 ≡ 工资 + 利息 + 租金 + 利润 ≡ 消费 + 储蓄 + 税收

即：$$Y = C + S + T$$

其中，$Y = C + S + (T_0 - T_r)$，$T_0$表示全部税收，$T_r$表示政府转移支付，用$T$表示政府净收入，$T = T_0 - T_r$。

---

### 三部门经济循环模型

**三部门经济的储蓄——投资恒等式**：

总需求：$Y = C + I + G$

总供给：$Y = C + S + T$

→ $I + G = S + T$

→ $I = S + (T - G)$

即：**投资 = 储蓄 = 私人储蓄 + 政府储蓄**

---

## 四部门经济循环模型

**四部门经济（Four Sector Economy）**是指由厂商、居民户、政府和国外这四种经济单位所组成的经济。

在这种经济中，国外的作用是：
- 作为国外生产要素的供给者
- 作为国内产品与劳务的需求者

---

### 四部门经济的储蓄——投资恒等式

总需求：$Y = C + I + G + (X - M)$

总供给：$Y = C + S + T + K_r$

$I + G + (X - M) = S + T + K_r$

$I = S + (T - G) + [K_r - (X - M)]$

其中：
- $S$代表居民私人储蓄
- $(T - G)$代表政府储蓄
- $K_r$是要素净流入
- $K_r - (X - M)$代表外国对本国的储蓄

即：**投资 = 储蓄 = 私人储蓄 + 政府储蓄 + 国外储蓄**

### 其他消费理论

**相对收入消费理论**：

美国经济学家杜森贝利（Duesenberry）认为消费者依据自己过去的消费习惯以及周围消费水准的影响来决定消费。

- **棘轮效应**：消费者易于随着收入增加而提高消费，但不易随收入减少而降低消费
- **示范效应**：消费行为还受周围消费水准的影响

长期消费函数是出自零点的直线，但短期的消费函数则是具有正截距的曲线。

---

### 生命周期消费理论

消费者根据自己一生的预期收入来安排消费，实现消费的平滑化。

---

### 永久收入消费理论

消费者根据永久收入而不是暂时收入来消费。

---

**题目**：

假定某经济的消费函数为 $C = 100 + 0.8Y_d$，$Y_d$为可支配收入，投资支出为 $I = 50$，政府购买支出为 $G = 200$，政府转移支付为 $T_r = 62.5$，税收为 $T = 250$。

求均衡的国民收入。

**参考答案**：

可支配收入：$Y_d = Y - T + T_r = Y - 250 + 62.5 = Y - 187.5$

由收入恒等式得：

$Y = C + I + G = 100 + 0.8(Y - 187.5) + 50 + 200$

所以均衡国民收入 $Y = 1000$

## 第4节 乘数论

---

### 投资乘数

投资乘数是指收入的变化与带来这种变化的投资支出的变化的比率。

例如，从投资角度看，若自发投资量是600亿美元，均衡的国民收入是8000亿美元；若投资增加到700亿美元，则国民收入会增加到8500亿美元。在这里，投资增加了100亿美元，收入增加500亿美元，增加的收入是增加的投资的5倍。

当总投资增加时，收入的增量将是投资增量的数倍。如果以$k$代表倍数，则$k$为投资乘数。

---

### 乘数产生的基本原理

**（投资对国民收入的第一轮增加）**

假定社会边际消费倾向为0.8：

- 社会居民收入增加80亿
- 生产消费品的生产要素所有者获得：工资、利息、利润、租金
- 消费增加80亿

**（投资对国民收入的第二轮增加）**

- 消费增加64亿
- ……（继续循环）

最终总效应 = 初始投资 × 乘数

### 三部门经济的AE-NI模型

**加入政府的三部门经济**：

从总支出角度看，国民收入 = 消费 + 投资 + 政府购买

$$Y = C + I + G$$

从总收入角度看，国民收入 = 消费 + 储蓄 + 税收

宏观均衡条件：$C + I = C + S$

**考虑税收的情况**：

1. 定量税，即税收量不随收入变动
2. 比例所得税，即随收入增量增加而增加税收量

### 税收乘数

税收乘数指收入变动与引起这种变动的税收变动的比率。

1. 比例税：税率变动对总收入的影响
2. 定量税：税收绝对量变动对总收入的影响
3. 比例与定量税同时存在的情形

$$k_T = -\frac{MPC}{1 - MPC}$$

---

### 税收乘数：定量税

当税收为定量税时：

$$k_T = -\frac{MPC}{1 - MPC}$$

---

### 比例税

当税收为比例税时：

税率乘数 = -$\frac{MPC}{1 - MPC}$ （具体推导略）

---

### 政府转移支付乘数

$$k_{T_r} = \frac{MPC}{1 - MPC}$$

---

### 平衡预算乘数

$$k_{平衡预算} = 1$$

### 课堂练习3：国民收入的决定（暨南大学2012年）

**题目**：

假设在一个两部门经济中，$Y$是收入，消费函数为 $C = 1000 + 0.8Y$，投资 $I = 1000$。（单位：10亿元）

（1）求均衡收入及相应的消费和储蓄额。

（2）当实际收入为12000时，求社会的非计划存货；并回答收入将如何变化，并解释收入变化的原因。

（3）如果把投资增加400，相应增加的均衡收入是多少？

（4）投资乘数是多少？

**参考答案**：

（1）均衡条件：$Y = C + I = 1000 + 0.8Y + 1000$

$Y = 10000$

消费 $C = 1000 + 0.8 × 10000 = 9000$

储蓄 $S = Y - C = 10000 - 9000 = 1000$

（2）非计划存货 $IU = Y - AE = 12000 - (9000 + 1000) = 2000$

收入将下降，因为企业发现库存超预期增加，会减少生产。

（3）投资乘数 $k = \frac{1}{1 - 0.8} = 5$

$ΔY = k × ΔI = 5 × 400 = 2000$

（4）投资乘数 $k = 5$
