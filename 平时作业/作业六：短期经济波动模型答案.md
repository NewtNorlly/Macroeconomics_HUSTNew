# 作业六：短期经济波动模型 答案

**第四章 短期经济波动模型：总需求-总供给分析**

---

## 一、选择题

1. 总需求曲线向右下方倾斜是因为（ ）

- A. 价格水平上升时，投资会减少
- B. 价格水平上升时，消费会减少
- C. 价格水平上升时，净出口会减少
- D. 以上都是 ✅

总需求曲线向右下方倾斜有三个效应同时作用：**庇古财富效应**（物价上升→实际财富缩水→消费减少）；**凯恩斯利率效应**（物价上升→实际货币供给减少→利率上升→投资减少）；**蒙代尔-弗莱明汇率效应**（物价上升→利率上升→资本流入→本币升值→净出口减少）。因此三种效应都成立，选D。


2. 总需求曲线向左方移动的原因是（ ）

- A. 技术进步
- B. 企业对经济前景悲观 ✅
- C. 政府支出增加
- D. 投入品价格下降

AD左移意味着在任一给定价格水平下总需求减少。企业对经济前景悲观会削减投资支出，投资减少直接降低总需求，AD曲线向左移动。A技术进步使AS右移；C政府支出增加使AD右移；D投入品价格下降影响AS曲线（右移），不影响AD。


3. 根据 IS-LM 模型，引起沿着总需求曲线向左上方移动的原因是（ ）

- A. 自发支出不变，名义货币供给不变，物价水平上升 ✅
- B. 自发支出不变，名义货币供给不变，物价水平下降
- C. 名义货币供给与物价水平不变，自发支出增加
- D. 名义货币供给与物价水平不变，自发支出减少

沿AD曲线移动由物价水平变动引起。物价上升→实际货币供给M/P减少→LM左移→利率上升→投资减少→收入减少（沿AD曲线向左上方移动）。A符合。B物价下降导致向右下方移动；C自发支出增加使整条AD曲线右移而非沿曲线移动；D同理使AD左移。


4. 在长期中，价格是有伸缩性的，总供给曲线是垂直的。因此，总需求曲线变动将（ ）

- A. 影响物价水平和产出
- B. 影响物价水平但不影响产出 ✅
- C. 不影响物价水平和产出
- D. 不影响物价水平但影响产出

长期AS曲线垂直（古典情形），产出由劳动、资本、技术等实际因素决定，处于充分就业水平。AD曲线移动只会改变价格水平，不影响产出。这是古典二分法的核心结论：名义变量不影响实际变量。


5. 价格水平下降时，下列说法正确的是（ ）

- A. 实际货币供给减少并使 LM 曲线右移
- B. 实际货币供给减少并使 LM 曲线左移
- C. 实际货币供给增加并使 LM 曲线右移 ✅
- D. 实际货币供给增加并使 LM 曲线左移

实际货币供给 = M/P。P下降→M/P增加→货币市场供过于求→利率下降以恢复均衡→LM曲线向右移动（在任一Y下r更低）。C正确。


6. 假设经济实现了充分就业，总供给曲线是垂直线，名义货币供给增加，（ ）

- A. 价格水平上升，产出水平增加
- B. 价格水平上升，产出水平不变 ✅
- C. 价格水平不变，产出水平增加
- D. 价格水平不变，产出水平减少

垂直AS（充分就业/古典情形）下，名义货币供给增加→AD右移→由货币数量论MV=PY，V和Y不变（Y在潜在水平），P同比例上升。产出不变，价格水平上升。B正确。


7. AD 和 LAS（长期总供给曲线）的交点表示（ ）

- A. 充分就业，货币市场不均衡
- B. 充分就业，产品市场和货币市场同时均衡 ✅
- C. 货币市场均衡，产品市场不均衡
- D. 以上都不正确

AD曲线本身就是IS-LM两条曲线推导而来，AD线上每一点都表示产品市场和货币市场同时均衡。AD与长期AS（LAS）的交点意味着在充分就业水平下，产品市场和货币市场同时达到均衡。B正确。


8. 古典总供给曲线存在的条件是（ ）

- A. 产出水平由充分就业水平决定
- B. 劳动力市场的均衡不受劳动力需求曲线移动的影响
- C. 劳动力市场的均衡不受劳动力供给曲线移动的影响
- D. 劳动力需求和劳动力供给立即对价格水平的变化作出调整 ✅

古典总供给曲线垂直的核心前提是价格和工资**完全弹性**，能立即调整以出清市场。即劳动力需求和劳动力供给能立即对价格水平变化作出反应，使得实际工资始终处于均衡水平，就业始终处于充分就业状态。A是结果而非条件；B、C不完全。D是根本条件。


9. 下列哪种情况下，财政政策不会影响产出水平？（ ）

- A. 价格黏性
- B. 价格刚性
- C. 工资刚性
- D. 工资完全弹性 ✅

工资完全弹性→劳动市场始终出清→产出始终处于充分就业水平→AS垂直（古典情形）。此时财政扩张完全挤出私人投资，产出不变，只有价格上升。A、B、C都属于凯恩斯情形，AS非垂直，财政政策有效。


10. 假定经济实现充分就业，总供给曲线是垂直线，扩张的财政政策将（ ）

- A. 提高价格水平和实际产出
- B. 提高价格水平但不影响实际产出 ✅
- C. 提高实际产出但不影响价格水平
- D. 对价格水平和产出均无影响

垂直AS（古典情形）下，扩张性财政政策（增加G或减税）使IS右移→AD右移。但AS垂直意味着产出固定在充分就业水平，AD右移只会推高价格，发生完全的挤出效应。B正确。


11. 当 AD 曲线保持不变，长期 AS 曲线右移时，价格（ ）

- A. 和产出都增加
- B. 和产出都减少
- C. 增加，产出减少
- D. 减少，产出增加 ✅

长期AS右移（技术进步、资本积累、劳动增加等）意味着潜在产出提高，价格水平在AD不变的情况下因供给增加而下降。因此产出增加，价格下降。D正确。


12. 在古典的价格完全灵活可变的经济中，下列哪种说法是错误的？（ ）

- A. 财政政策对实际变量没有影响 ✅
- B. 货币政策对实际变量没有影响
- C. 总需求变动不影响就业
- D. 总需求变动不影响实际工资

在古典价格完全弹性的经济中，财政政策虽然不影响总产出（GDP），但扩张性财政政策会提高实际利率（因为政府借款推高可贷资金市场利率），而实际利率是实际变量。财政政策还会改变产出的构成（政府购买替代私人投资）。因此A"财政政策对实际变量没有影响"是错误的。B货币政策不影响实际变量（货币中性，不仅产出不变，实际利率也不变）是正确的。C和D也是正确的：就业由劳动市场决定，总需求不影响；实际工资由劳动供需决定，总需求变动只影响价格水平而不影响实际工资。


13. 货币供应量的增加会使（ ）

- A. LM 曲线向左上方移动
- B. IS 曲线向右上方移动
- C. AS 曲线向右上方移动
- D. AD 曲线向右上方移动 ✅

货币供给增加→LM右移→利率下降→投资增加→在任一价格水平下产出增加→AD曲线向右移动。货币供给变动不直接影响IS（产品市场）和AS（供给面）。D正确。


14. 凯恩斯主义认为，凯恩斯总供给曲线的政策含义是（ ）

- A. 需求管理政策无效
- B. 供给管理政策无效
- C. 需求管理政策有效 ✅
- D. 供给管理政策有效

凯恩斯总供给曲线呈"反L"形（水平段+垂直段）。在萧条时期（水平段），经济存在大量闲置资源，增加总需求可以在不提高价格的情况下增加产出。因此需求管理政策（财政政策和货币政策）是有效的，这是凯恩斯主义的核心政策主张。


15. 当一国经济存在大量的闲置资源时，AS 曲线是水平线，此时（ ）

- A. 总需求的增加对产出没有影响
- B. 总供给通常不会发生变动
- C. 总需求的增加使产出增加，对价格几乎没有影响 ✅
- D. 总供给的增加使产出增加，价格上升

大量闲置资源对应凯恩斯总供给曲线的水平段（极端萧条情形）。此时企业可以在不变价格下增加生产，AD增加完全转化为产出增加，价格水平几乎不变。这正是凯恩斯"有效需求不足"理论的政策依据。C正确。


16. 垂直的长期总供给曲线表明，如果价格可以充分调节，那么（ ）

- A. 任何价格水平下，潜在的和实际的国民收入都是一致的 ✅
- B. 产出仅取决于总需求水平
- C. 均衡的实际国民收入不能确定
- D. 价格水平仅由总供给确定

长期AS垂直意味着价格可以充分调节以确保经济始终在潜在（充分就业）产出水平运行，实际国民收入恒等于潜在国民收入。B错误（产出取决于供给面的劳动、资本、技术）；C错误（均衡收入由潜在产出确定）；D错误（价格由AD和AS共同决定）。A正确。


17. 当 AS 曲线有正斜率时，政府对不利的供给冲击实行紧缩性货币政策，结果将（ ）

- A. 通货膨胀率和自然失业率都降低
- B. 通货膨胀率降低，失业率上升 ✅
- C. 通货膨胀率和失业率都上升
- D. AS 曲线回到原来的位置

不利供给冲击（如石油涨价）→AS左移→价格上升（通胀）+产出下降（失业上升）=滞胀。紧缩货币政策→AD左移→价格回落（通胀降低）但产出进一步下降（失业更高）。因此通胀降低、失业上升。B正确。


18. AD-AS 模型与 IS-LM 模型相比，其改变的一个基本假设是（ ）

- A. 充分就业
- B. 货币需求受利率和收入的影响
- C. 投资由利率决定
- D. 价格变化 ✅

IS-LM模型假设价格水平固定不变（短期分析），在此前提下分析利率和收入的决定。AD-AS模型将价格水平内生化，允许价格变动，从而可以同时分析产出和价格水平的决定。这是两个模型最根本的区别。D正确。


19. 以下关于总需求-总供给模型的表述正确的是（ ）

- A. 凯恩斯总需求-总供给模型的供给曲线呈水平形状
- B. 凯恩斯总需求-总供给模型中，总产量水平主要由总需求决定
- C. 古典总需求-总供给模型的总供给曲线呈垂直形状
- D. 以上都正确 ✅

三个选项都是正确的：A凯恩斯AS在萧条时水平；B凯恩斯情形下产出由总需求决定（"需求创造自己的供给"）；C古典AS垂直（产出由供给面决定）。D正确。


20. 假设某国某年出现严重自然灾害，使所有当年农作物产量锐减，则会出现（ ）

- A. 总供给减少，价格水平上升，国民收入减少的滞胀现象 ✅
- B. 总供给减少，价格水平下降，国民收入减少的经济衰退现象
- C. 总需求减少，价格水平上升，国民收入减少的滞胀现象
- D. 总需求减少，价格水平下降，国民收入减少的经济衰退现象

自然灾害是典型的**不利供给冲击**，使AS曲线左移。在AD不变的情况下，价格上升而产出下降，即"滞胀"（停滞+通货膨胀）。这是20世纪70年代石油危机期间发达国家经历的典型现象。A正确。

## 二、名词解释

**1. 总需求**

总需求（Aggregate Demand，AD）是指在一定时期内，一个经济中所有经济主体（家庭、企业、政府和国外部门）在不同价格水平下愿意且能够购买的最终物品和服务的总量。总需求由四个部分构成：$AD = C + I + G + (X - M)$，即消费、投资、政府购买和净出口之和。总需求曲线向右下方倾斜，反映价格水平与总需求量之间的反向关系。总需求曲线可以通过IS-LM模型推导，其背后的传导机制是：价格水平变动→实际货币供给变动→利率变动→投资变动→产出变动。

**2. 总供给**

总供给（Aggregate Supply，AS）是指在一定时期内，一个经济中所有企业在不同价格水平下愿意且能够生产的最终物品和服务的总量。总供给 = 总收入 = GDP。总供给主要由劳动、资本存量、自然资源和技术水平决定。根据价格和工资调整速度的不同假设，总供给曲线有三种形态：古典总供给曲线（垂直）、凯恩斯总供给曲线（水平+垂直的"反L"形）和常规总供给曲线（向右上方倾斜）。

**3. 凯恩斯主义的总供给曲线**

凯恩斯主义的总供给曲线呈"反L"形：在达到充分就业产出之前为水平线，达到充分就业后转为垂直线。其核心假设是货币工资具有向下刚性（只能升不能降），且存在货币幻觉。在经济萧条、存在大量闲置资源时，企业可以在不变的工资和价格水平下增加产出，因此AS为水平线；当经济达到充分就业后，任何总需求的增加只能推高价格而无法增加产出，AS转为垂直线。凯恩斯AS曲线的政策含义是：在萧条时期，需求管理政策是有效的，可以在不引发通货膨胀的情况下增加产出和就业。

**4. 工资黏性假说**

工资黏性假说是解释短期总供给曲线向右上方倾斜的主要理论之一。该假说认为，名义工资在短期内不能随价格水平的变化而迅速调整，即工资具有"黏性"。具体而言，工资通常通过长期合同确定，在合同期内固定不变。当价格水平意外下降时，名义工资不变意味着实际工资上升，企业劳动成本增加，企业减少雇佣和产量。反之，价格意外上升时实际工资下降，企业增加雇佣和产量。因此，由于工资黏性，短期中价格水平与产出呈同向关系，AS曲线向右上方倾斜。长期中，合同到期后工资可以调整，经济回到充分就业水平。

## 三、简答题

**1. 总需求曲线为何向右下方倾斜？**

总需求曲线向右下方倾斜的原因可以从以下三个效应来解释：

**（1）庇古财富效应（实际余额效应）**

价格水平下降→人们持有的货币和金融资产的实际价值（实际财富）上升→消费者感到更富有→消费支出增加→总需求量增加。反之，价格水平上升使实际财富缩水，消费减少。公式表达：$P \downarrow \Rightarrow \frac{M}{P} \uparrow \Rightarrow C \uparrow \Rightarrow AD \uparrow$。

**（2）凯恩斯利率效应**

价格水平下降→实际货币供给（$M/P$）增加→货币市场供过于求→利率下降→企业投资成本降低→投资支出增加→总需求量增加。这是AD曲线向下倾斜最主要的传导渠道。公式表达：$P \downarrow \Rightarrow \frac{M}{P} \uparrow \Rightarrow r \downarrow \Rightarrow I \uparrow \Rightarrow AD \uparrow$。

**（3）蒙代尔-弗莱明汇率效应（开放经济）**

价格水平下降→利率下降→资本外流寻求更高收益→本币在外汇市场贬值→本国商品相对便宜、外国商品相对昂贵→出口增加、进口减少→净出口增加→总需求量增加。公式表达：$P \downarrow \Rightarrow r \downarrow \Rightarrow e \downarrow \Rightarrow NX \uparrow \Rightarrow AD \uparrow$。

**小结**：三个效应方向一致：价格水平下降均导致总需求量增加，因此AD曲线向右下方倾斜。

**2. 导致总需求曲线移动的因素有哪些？**

总需求曲线的移动是在任一给定价格水平下，总需求水平发生的变化，表现为整条AD曲线向左或向右平移。导致AD移动的因素包括：

**（1）消费支出的变动（$C$）**

- 居民财富变化（股市上涨→财富增加→消费增加→AD右移）
- 消费者信心和预期变化（对未来收入乐观→消费增加→AD右移）
- 税收政策变化（减税→可支配收入增加→消费增加→AD右移）

**（2）投资支出的变动（$I$）**

- 利率变化（货币供给增加→利率下降→投资增加→AD右移）
- 企业对未来经济前景的预期（"动物精神"：乐观→投资增加→AD右移）
- 投资税收优惠（投资补贴→投资成本降低→投资增加→AD右移）
- 技术进步（新技术带来投资机会→AD右移）

**（3）政府购买的变动（$G$）**

- 扩张性财政政策（增加基础设施建设、国防支出等→AD右移）
- 紧缩性财政政策（削减政府支出→AD左移）

**（4）净出口的变动（$X - M$）**

- 国外经济状况变化（贸易伙伴国经济繁荣→本国出口增加→AD右移）
- 汇率变动（本币贬值→出口增加、进口减少→净出口增加→AD右移）
- 贸易政策变化（关税降低→可能影响净出口方向不定）

**（5）货币供给的变动**

- 货币供给增加→LM右移→利率下降→投资增加→AD右移
- 货币供给减少→AD左移

**3. 简述总供给曲线的三种类型。**

根据货币工资和价格水平调整所需时间的长短，总供给曲线分为三种类型：

**（1）古典总供给曲线（长期）**

- **形状**：垂直于潜在产出水平（$Y_f$）的一条直线。
- **假设**：价格和工资完全弹性，能立即调整以出清所有市场。劳动市场始终处于充分就业均衡。
- **含义**：产出完全由供给面的实际因素（资本存量、劳动数量、技术水平）决定，与价格水平无关。总需求变动只影响价格水平，不影响产出。
- **政策含义**：需求管理政策无效；增加产出必须依靠供给面政策（促进技术进步、资本积累等）。

**（2）凯恩斯总供给曲线（极端短期）**

- **形状**：呈"反L"形。在达到充分就业之前为水平线，充分就业后为垂直线。
- **假设**：货币工资向下刚性（只能升不能降），价格水平也不能向下调整。存在大量闲置资源（资本和劳动）。
- **含义**：在萧条时期，企业可以在不变价格下增减产出，产出完全由总需求决定。达到充分就业后，总需求增加只能推高价格。
- **政策含义**：萧条时期需求管理政策非常有效，可以在不引起通胀的情况下增加产出。

**（3）常规总供给曲线（短期）**

- **形状**：向右上方倾斜的曲线，斜率随产出接近充分就业而增大。
- **假设**：存在工资黏性、价格黏性或工人错觉等摩擦因素。价格和工资在短期不能立即完全调整。
- **含义**：价格水平上升时，由于名义工资调整滞后，实际工资下降，企业增加雇佣和产出，因此价格与产出同向变动。当产出超过充分就业水平后，斜率越来越大。
- **政策含义**：需求管理政策在短期有效，但会伴随价格水平变化；存在通胀与失业的短期权衡取舍。

**小结**：三种AS曲线的核心区别在于价格和工资的调整速度，反映了不同时间维度下经济运行的不同逻辑。

**4. 导致总供给曲线移动的因素有哪些？**

总供给曲线的移动意味着在任一给定价格水平下，经济的生产能力发生了变化。导致AS移动的因素包括：

**（1）劳动供给的变动**

- 人口增长、移民增加→劳动供给增加→AS右移
- 劳动力参工率提高→AS右移
- 退休年龄延后→AS右移

**（2）资本存量的变动**

- 投资增加→资本积累→生产能力提高→AS右移
- 自然灾害或战争破坏资本存量→AS左移

**（3）自然资源的变动**

- 新矿藏发现→资源供给增加→AS右移
- 石油危机、原材料短缺→AS左移
- 天气变化影响农业生产→AS左移

**（4）技术进步**

- 技术创新→生产率提高→同样投入可获得更多产出→AS右移
- 管理制度改进→效率提升→AS右移

**（5）预期价格水平的变动**

- 工人预期未来价格上升→要求提高名义工资→企业成本上升→短期AS左移
- 预期价格下降→短期AS右移（该机制仅影响短期AS，不影响长期AS）

**（6）制度与政策因素**

- 最低工资法提高→企业成本上升→短期AS左移
- 减少管制→企业经营成本降低→AS右移
- 税收政策：企业税负增加→AS左移；减税→AS右移

## 四、计算题

**1. 如总供给曲线为 $AS = 250$，总需求曲线为 $AD = 300 - 25P$。试求：**

**（1）供求均衡点的价格水平和收入水平为多少？**

**解：**

均衡条件：$AS = AD$，即

$$250 = 300 - 25P$$

$$25P = 300 - 250 = 50$$

$$P = \frac{50}{25} = 2$$

代入 $AS = 250$ 得均衡收入 $Y = 250$。

**答：均衡价格水平 $P = 2$，均衡收入水平 $Y = 250$。**

**（2）如总需求曲线向右平移 10%，其他条件不变，新的供求均衡点的价格水平和收入水平。**

**解：**

总需求曲线向右平移10%，即将原AD曲线纵截距乘以1.1（AD曲线斜率不变，仅平移）：

$$AD_{新} = 1.1 \times (300 - 25P) = 330 - 27.5P$$

均衡条件：

$$250 = 330 - 27.5P$$

$$27.5P = 330 - 250 = 80$$

$$P = \frac{80}{27.5} \approx 2.91$$

由于AS垂直（古典情形），均衡收入仍为 $Y = 250$。

**答：新的均衡价格水平 $P \approx 2.91$，均衡收入水平 $Y = 250$（不变）。**

**（3）如总供给曲线向左平移 10%，其他条件不变，新的供求均衡点的价格水平和收入水平。**

**解：**

总供给曲线向左平移10%：

$$AS_{新} = 250 \times 0.9 = 225$$

均衡条件（AD不变）：

$$225 = 300 - 25P$$

$$25P = 300 - 225 = 75$$

$$P = \frac{75}{25} = 3$$

均衡收入 $Y = 225$。

**答：新的均衡价格水平 $P = 3$，均衡收入水平 $Y = 225$。**

**2. 假定一个两部门的经济由下述关系式描述：**

$$C = 100 + 0.8Y$$

$$I = 150 - 6r$$

$$L = 0.2Y - 4r$$

$$M = 150$$

设 $P$ 为价格水平。试求：

**（1）总需求函数。**

**解：**

**第一步：推导 IS 曲线**

产品市场均衡 $Y = C + I$：

$$Y = 100 + 0.8Y + 150 - 6r$$

$$Y = 250 + 0.8Y - 6r$$

$$0.2Y = 250 - 6r$$

$$Y = 1250 - 30r \quad \text{（IS曲线）}$$

**第二步：推导 LM 曲线**

货币市场均衡 $\frac{M}{P} = L$：

$$\frac{150}{P} = 0.2Y - 4r$$

$$0.2Y = \frac{150}{P} + 4r$$

$$Y = \frac{750}{P} + 20r \quad \text{（LM曲线）}$$

**第三步：联立消去 $r$ 得总需求函数**

由 IS：$r = \frac{1250 - Y}{30}$

代入 LM：

$$Y = \frac{750}{P} + 20 \times \frac{1250 - Y}{30}$$

$$Y = \frac{750}{P} + \frac{25000 - 20Y}{30}$$

$$Y = \frac{750}{P} + \frac{2500}{3} - \frac{2}{3}Y$$

$$\frac{5}{3}Y = \frac{750}{P} + \frac{2500}{3}$$

$$Y = \frac{3}{5} \times \frac{750}{P} + \frac{3}{5} \times \frac{2500}{3}$$

$$Y = \frac{450}{P} + 500$$

**答：总需求函数为 $\displaystyle Y = 500 + \frac{450}{P}$。**

**（2）若 $P = 1$，均衡的收入和利率各为多少？**

**解：**

代入 $P = 1$ 到总需求函数：

$$Y = 500 + \frac{450}{1} = 950$$

由 IS 曲线 $Y = 1250 - 30r$，代入 $Y = 950$：

$$950 = 1250 - 30r$$

$$30r = 300$$

$$r = 10$$

**验证**：$C = 100 + 0.8 \times 950 = 860$，$I = 150 - 6 \times 10 = 90$，$C + I = 950 = Y$ ✓。

**答：$P = 1$ 时，均衡收入 $Y = 950$，均衡利率 $r = 10$（即 $10\%$）。**

**（3）若该经济的总供给函数为 $AS = 800 + 150P$，求均衡收入和价格水平。**

**解：**

均衡条件 $AD = AS$：

$$500 + \frac{450}{P} = 800 + 150P$$

两边同乘 $P$：

$$500P + 450 = 800P + 150P^2$$

整理为标准二次方程：

$$150P^2 + 300P - 450 = 0$$

除以 150：

$$P^2 + 2P - 3 = 0$$

因式分解：

$$(P + 3)(P - 1) = 0$$

$$P = 1 \quad \text{或} \quad P = -3 \quad \text{（舍去负根）}$$

代入 AS（或 AD）：

$$Y = 800 + 150 \times 1 = 950$$

**答：均衡价格水平 $P = 1$，均衡收入 $Y = 950$。**

**3. 已知一国的宏观经济可以用下列方程式来描述：**

$$C = 120 + 0.8Y$$

$$I = 50 - 200r$$

$$Y = C + I$$

$$L = (0.5Y - 500r)P$$

$$M = 500$$

（注：$M = 500$ 为名义货币供给，$L$ 为名义货币需求）

试求：

**（1）该国的总需求函数。**

**解：**

**第一步：推导 IS 曲线**

产品市场均衡 $Y = C + I$：

$$Y = 120 + 0.8Y + 50 - 200r$$

$$Y = 170 + 0.8Y - 200r$$

$$0.2Y = 170 - 200r$$

$$Y = 850 - 1000r \quad \text{（IS曲线）}$$

**第二步：推导 LM 曲线**

货币市场均衡 $M = L$：

$$500 = (0.5Y - 500r)P$$

$$\frac{500}{P} = 0.5Y - 500r$$

$$0.5Y = \frac{500}{P} + 500r$$

$$Y = \frac{1000}{P} + 1000r \quad \text{（LM曲线）}$$

**第三步：消去 $r$ 得总需求函数**

由 IS：$r = \frac{850 - Y}{1000} = 0.85 - 0.001Y$

代入 LM：

$$Y = \frac{1000}{P} + 1000(0.85 - 0.001Y)$$

$$Y = \frac{1000}{P} + 850 - Y$$

$$2Y = \frac{1000}{P} + 850$$

$$Y = 425 + \frac{500}{P}$$

**答：总需求函数为 $\displaystyle Y = 425 + \frac{500}{P}$。**

**（2）如果在 2008 年该国的价格总水平是 2，该国宏观经济均衡时国民收入利率分别是多少？**

**解：**

$P = 2$，代入总需求函数：

$$Y = 425 + \frac{500}{2} = 425 + 250 = 675$$

由 IS 曲线 $Y = 850 - 1000r$，代入 $Y = 675$：

$$675 = 850 - 1000r$$

$$1000r = 175$$

$$r = 0.175 = 17.5\%$$

**验证**：

- $C = 120 + 0.8 \times 675 = 660$
- $I = 50 - 200 \times 0.175 = 50 - 35 = 15$
- $C + I = 660 + 15 = 675 = Y$ ✓
- 实际货币需求 $= 0.5 \times 675 - 500 \times 0.175 = 337.5 - 87.5 = 250$，$M/P = 500/2 = 250$ ✓

**答：均衡国民收入 $Y = 675$，均衡利率 $r = 17.5\%$。**

**4. 假设有一个四部门经济存在以下关系：**

消费函数 $C = 300 + 0.8Y_d$，税收 $t = 0.2Y$，投资 $I = 200 - 1500r$，政府支出 $G = 200$，净出口 $N = 100 - 0.04Y - 500r$；实际货币需求 $L = 0.5Y - 2000r$，名义货币供给 $M = 550$。

试求：

**（1）总需求函数。**

**解：**

**第一步：推导 IS 曲线**

可支配收入：$Y_d = Y - T = Y - 0.2Y = 0.8Y$

产品市场均衡 $Y = C + I + G + N$：

$$Y = 300 + 0.8 \times 0.8Y + (200 - 1500r) + 200 + (100 - 0.04Y - 500r)$$

$$Y = 300 + 0.64Y + 200 - 1500r + 200 + 100 - 0.04Y - 500r$$

$$Y = 800 + 0.6Y - 2000r$$

$$0.4Y = 800 - 2000r$$

$$Y = 2000 - 5000r \quad \text{（IS曲线）}$$

**第二步：推导 LM 曲线**

货币市场均衡 $\frac{M}{P} = L$：

$$\frac{550}{P} = 0.5Y - 2000r$$

$$0.5Y = \frac{550}{P} + 2000r$$

$$Y = \frac{1100}{P} + 4000r \quad \text{（LM曲线）}$$

**第三步：消去 $r$ 得总需求函数**

由 IS：$r = \frac{2000 - Y}{5000} = 0.4 - 0.0002Y$

代入 LM：

$$Y = \frac{1100}{P} + 4000(0.4 - 0.0002Y)$$

$$Y = \frac{1100}{P} + 1600 - 0.8Y$$

$$1.8Y = \frac{1100}{P} + 1600$$

$$Y = \frac{1100}{1.8P} + \frac{1600}{1.8}$$

$$Y = \frac{5500}{9P} + \frac{8000}{9}$$

**答：总需求函数为 $\displaystyle Y = \frac{8000}{9} + \frac{5500}{9P}$（或 $Y \approx 888.89 + \frac{611.11}{P}$）。**

**（2）$P = 1$ 时的均衡收入和利率。**

**解：**

$P = 1$，代入总需求函数：

$$Y = \frac{8000}{9} + \frac{5500}{9} = \frac{13500}{9} = 1500$$

由 IS 曲线 $Y = 2000 - 5000r$，代入 $Y = 1500$：

$$1500 = 2000 - 5000r$$

$$5000r = 500$$

$$r = 0.1 = 10\%$$

**验证**：

- $Y_d = 0.8 \times 1500 = 1200$
- $C = 300 + 0.8 \times 1200 = 300 + 960 = 1260$
- $I = 200 - 1500 \times 0.1 = 200 - 150 = 50$
- $G = 200$
- $N = 100 - 0.04 \times 1500 - 500 \times 0.1 = 100 - 60 - 50 = -10$
- $C + I + G + N = 1260 + 50 + 200 - 10 = 1500 = Y$ ✓
- $M/P = 550/1 = 550$，$L = 0.5 \times 1500 - 2000 \times 0.1 = 750 - 200 = 550$ ✓

**答：$P = 1$ 时，均衡收入 $Y = 1500$，均衡利率 $r = 10\%$。**
