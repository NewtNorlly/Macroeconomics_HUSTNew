# 作业五：产品市场和货币市场的共同均衡 答案

**第3课 IS-LM 模型**

---

## 一、选择题

1. IS 曲线上的每一点都表示（ ）

- A.使投资等于储蓄的均衡货币额
- B.产品市场投资等于储蓄时的收入与利率的组合 ✅
- C.产品市场和货币市场都均衡时的收入与利率的组合
- D.货币市场货币需求和货币供给相等时的均衡货币额

IS 曲线描述产品市场均衡（$I = S$）时收入与利率的各种组合，线上每一点都满足投资等于储蓄的条件。只有 IS 与 LM 的交点才同时满足两个市场均衡。

2. LM 曲线上的每一点都表示（ ）

- A.使投资等于储蓄的均衡货币额
- B.产品市场投资等于储蓄时的收入与利率的组合
- C.产品市场和货币市场都均衡时的收入与利率的组合
- D.货币市场货币需求和货币供给相等时的收入与利率的组合 ✅

LM 曲线描述货币市场均衡（$L = M$）时收入与利率的各种组合，线上每一点都满足货币需求等于货币供给的条件。

3. IS 曲线的斜率取决于（ ）

- A.投资需求对利率变动的反应程度 ✅
- B.投资需求对收入变动的反应程度
- C.货币需求对利率变动的反应程度
- D.货币需求对收入变动的反应程度

IS 曲线斜率（绝对值）为 $\frac{1-b}{d}$，其中 $d$ 是投资对利率的敏感程度（$d$ 越大，IS 越平坦），$b$ 是边际消费倾向。斜率主要取决于投资需求对利率变动的反应程度。

4. LM曲线的斜率取决于（ ）

- A.投资需求对利率变动的反应程度
- B.投资需求对收入变动的反应程度
- C.货币需求对利率变动的反应程度 ✅
- D.边际消费倾向

LM 曲线斜率为 $\frac{k}{h}$，其中 $k$ 是货币需求对收入的敏感程度，$h$ 是货币需求对利率的敏感程度。$h$ 越大，LM 越平坦。

5. 在其他条件不变的情况下，政府购买支出增加会使IS曲线（ ）

- A.向左移
- B.向右移动 ✅
- C.保持不变
- D.发生移动，但方向不确定

政府购买增加属于扩张性财政政策，在任一利率水平下总需求增加，IS 曲线向右移动。移动幅度为 $k_g \times \Delta G$。

6. 按照凯恩斯的货币需求理论，利率上升，货币需求量将（ ）

- A.增加
- B.减少 ✅
- C.不变
- D.可能增加，也可能减少

货币需求 $L = L_1(Y) + L_2(r) = kY - hr$。投机动机的货币需求 $L_2$ 与利率负相关：利率上升，持有货币的机会成本增加，债券价格下降，人们倾向于购买债券而非持有货币。

7. 在 IS 曲线和 LM 曲线的交点（ ）

- A.经济一定处于充分就业的状态
- B.经济一定处于非充分就业的状态
- C.经济有可能处于充分就业的状态 ✅
- D.经济资源一定得到了充分利用

IS-LM 交点只保证产品市场和货币市场同时均衡，但交点对应的国民收入可能低于、等于或高于充分就业的国民收入。历史上多数时期均衡收入低于充分就业水平。

8. 货币市场和产品市场同时均衡出现于（ ）

- A.各种收入水平和利率上
- B.一种收入水平和利率上 ✅
- C.各种收入水平和一种利率上
- D.一种收入水平和各种利率上

IS 和 LM 各代表一系列利率与收入的组合，但两条曲线只有一个交点，因此两个市场同时均衡的利率和收入组合是唯一的。

9. 当 IS 和 LM 曲线出现同方向的移动时，变量的变动方向能够确定（ ）

- A.r
- B.y ✅
- C.r和y
- D.以上都不正确

IS 和 LM 同方向（如同向右）移动时，国民收入一定增加；但利率变动方向不确定：IS 右移使利率上升，LM 右移使利率下降，最终利率取决于两者移动幅度的相对大小。

10. （ ）会使产品和货币市场同时均衡时的国民收入减少

- A.IS 曲线和 LM 曲线都向右边移动
- B.IS 曲线和 LM 曲线都向左边移动 ✅
- C.IS 曲线不变，LM曲线向右边移动
- D.IS 曲线向右边移动，LM 曲线保持不变

IS 和 LM 都左移，两个市场同时紧缩，均衡国民收入必然减少。

11. 给定消费函数为 $C=40+0.8Y$，定量税 $T=20$，投资函数为 $I=70-400r$，则税收再增加10单位会使IS曲线（ ）

- A.右移10单位
- B.左移10单位
- C.右移40单位
- D.左移40单位 ✅

IS 方程：$Y = 40 + 0.8(Y - 20) + 70 - 400r = 0.8Y + 94 - 400r$，整理得 $Y = 470 - 2000r$。
税收乘数 $k_T = -\frac{b}{1-b} = -\frac{0.8}{0.2} = -4$。
$\Delta T = 10$，$\Delta Y = -4 \times 10 = -40$，IS 左移 40 单位。

12. 减税会使IS曲线发生移动，下列（ ）情况会加大IS曲线的移动

- A.人们察觉到税收变动是暂时的
- B.人们察觉到税收变动是永久的 ✅
- C.人们已经事先预期到税收的这一变动
- D.人们知道，除了死亡和税收，没有可以肯定的事情

根据持久收入假说，永久性减税被消费者视为持久收入的增加，消费增加幅度大；暂时性减税对持久收入影响小，大部分会被储蓄起来。因此永久减税对 IS 的移动效果更强。

13. 在LM曲线的古典区域中，（ ）

- A.财政政策不会对总产出产生影响 ✅
- B.挤出不会发生
- C.投资不会对利率变动做出反应
- D.所得税增加不能减少预算赤字

古典区域对应 LM 垂直段（$h \to 0$），利率极高，投机性货币需求为零。此时财政扩张完全挤出私人投资，$Y$ 不变。货币政策完全有效。

14. 假定货币需求函数为 $L=kY-hr$，货币供给增加10亿美元而其他条件不变，则会使LM（ ）

- A.右移 10 亿美元
- B.右移k乘以10亿美元
- C.右移10亿美元除以k（即 $10/k$） ✅
- D.右移k除以10亿美元（即 $k/10$）

LM 方程：$Y = \frac{h}{k}r + \frac{M}{kP}$。货币供给增加 $\Delta M$，LM 水平右移 $\frac{\Delta M}{k}$（令 $r$ 不变时 $Y$ 的增加量）。

15. 利率和收入的组合点出现在IS曲线的右上方、LM曲线的左上方的区域，则表示（ ）

- A.投资小于储蓄，且货币需求小于货币供给 ✅
- B.投资小于储蓄，且货币供给小于货币需求
- C.投资大于储蓄，且货币需求小于货币供给
- D.投资大于储蓄，且货币需求大于货币供给

IS 右上方：给定利率下的收入高于均衡收入，$I < S$（产品市场供过于求）。
LM 左上方：给定收入下的利率高于均衡利率，$L < M$（货币市场供过于求）。

16. 货币供给增加使LM曲线右移，若要均衡收入变动接近于LM曲线的移动量，则必须（ ）

- A.LM曲线陡峭，IS曲线也陡峭
- B.LM曲线和IS曲线一样平缓
- C.LM曲线陡峭而IS曲线平缓 ✅
- D.LM曲线平缓而IS曲线陡峭

LM 陡峭（$h$ 小）+ IS 平缓（$d$ 大）→ 货币政策效果最大。IS 平缓意味着投资对利率高度敏感，LM 陡峭意味着货币供给增加能大幅降低利率且不被投机需求吸收。

17. 假定IS和LM曲线交点所表示的均衡国民收入低于充分就业的国民收入。根据IS-LM模型，如果不让利率上升，政府应该（ ）。

- A.增加投资
- B.在增加投资的同时增加货币供给 ✅
- C.减少货币供给
- D.在减少货币供给的同时减少投资

要增加 $Y$ 又不让 $r$ 上升，需要同时使用扩张性财政政策（IS 右移，$Y$↑$r$↑）和扩张性货币政策（LM 右移，$Y$↑$r$↓）。两者配合可使 $Y$ 增加而 $r$ 不变，避免挤出效应。

18. 当（ ）时，人们倾向于持有更多的货币。

- A.物价上涨，名义利率升高
- B.物价下跌，名义利率下降 ✅
- C.物价上涨，名义利率下降
- D.物价下跌，名义利率升高

名义利率下降 → 持有货币的机会成本降低 → 投机性货币需求增加。物价下跌 → 实际货币供给增加 → 利率进一步下降。两者共同推动货币需求上升。

19. 为交易动机所持有的货币需求产生于（ ）

- A.未来收入和支出的不确定性
- B.收入和支出在时间上的差异性 ✅
- C.对未来利率变动趋势的预期
- D.货币的流动性

交易动机源于日常购买支付的需要。收入和支出在时间上不完全同步（如月初领工资、整月支出），因此需要持有一定货币以应对日常交易。

20. 投机性货币需求的理论表明（ ）

- A.利率越高，债券价格越低，人们预期债券价格越会下降，不愿购买更多债券
- B.利率越高，债券价格越低，人们预期债券价格回涨可能性越大，因而越愿意购买更多债券 ✅
- C.利率越低，债券价格越高，人们为购买债券需求的货币就越多
- D.利率越低，债券价格越高，人们预期债券价格可能要上升，希望购买更多债券

利率极高时债券价格极低，人们预期债券价格只会回升不会继续下跌，因此将货币换成债券（投机性货币需求趋于零）。利率极低时则相反，人们预期债券价格只会下跌，持有债券风险大，宁愿持有货币（流动性陷阱）。

## 二、名词解释

**1、资本的边际效率**

凯恩斯提出的概念。是一种贴现率，它使资本品在使用期内各期预期收益的现值之和恰好等于该资本品的供给价格或重置成本。如果 MEC 大于市场利率，投资就有利可图；MEC 随投资增加而递减。它是企业投资决策的核心依据。

**2、流动性偏好**

人们愿意以货币形式持有财富的心理动机。凯恩斯认为，货币是流动性最强的资产，人们持有货币可以获得随时交易的便利性和灵活性。持有不生息的货币意味着放弃利息收益，这是流动性偏好的代价。

**3、流动性偏好理论**

凯恩斯的利率决定理论。认为利率不是由储蓄和投资决定，而是由货币的供给和需求决定。货币供给由中央银行外生控制，货币需求由交易动机、预防动机和投机动机三个因素决定。利率的调整使得货币供给等于货币需求。当利率极低时会出现"流动性陷阱"，货币供给增加无法进一步降低利率。

## 三、简答题

**1、IS曲线为什么向右下方倾斜？**

IS 曲线反映产品市场均衡（$I = S$）时利率与收入的组合关系。

**传导机制**：
利率下降 → 投资成本降低 → 投资增加 → 通过乘数效应 → 国民收入增加。

因此，利率 $r$ 与收入 $Y$ 在产品市场均衡时呈反向关系：$r$ 越低，$Y$ 越高。IS 曲线向右下方倾斜。

**数学表达**：由 $Y = \frac{a + e + G - bT}{1-b} - \frac{d}{1-b}r$，斜率为 $-\frac{1-b}{d} < 0$。

**2、LM曲线为什么向右上方倾斜？**

LM 曲线反映货币市场均衡（$L = M$）时利率与收入的组合关系。

**传导机制**：
收入增加 → 交易动机和预防动机的货币需求增加 → 在货币供给固定的条件下 → 利率必须上升以减少投机动机的货币需求 → 维持货币市场均衡。

因此，利率 $r$ 与收入 $Y$ 在货币市场均衡时呈正向关系：$Y$ 越高，$r$ 越高。LM 曲线向右上方倾斜。

**数学表达**：$r = \frac{k}{h}Y - \frac{M}{hP}$，斜率为 $\frac{k}{h} > 0$。

**3、投资是如何决定的？怎样看待其决定因素的地位和作用？**

投资取决于利率和资本边际效率的比较。决定因素包括：

1. **利率**（首要因素）：与投资反向变动。利率是投资的资金成本，利率越低，投资越有利可图。在投资函数 $I = e - dr$ 中，$d$ 反映投资对利率的敏感程度。

2. **预期利润率（资本的边际效率）**：与投资同向变动。预期收益越高，投资越有利。受经济周期、技术进步、市场前景等因素影响。

3. **折旧**：与投资同向变动。资本存量越大，折旧越多，重置投资需求越大。

4. **预期通货膨胀率**：与投资同向变动。通胀降低实际利率，企业实际债务负担减轻，刺激投资。

**地位和作用**：利率是可调控的政策变量，是货币政策传导的核心环节；预期利润率受"动物精神"支配，波动大，是经济周期波动的重要来源；折旧和通胀起辅助作用。

**4、简述人们持有货币的三种动机**

凯恩斯将货币需求分为三种动机：

1. **交易动机**：为日常购买物品和服务而持有货币。取决于收入水平，收入越高，交易量越大，交易动机货币需求越多。$L_1 = kY$。

2. **预防动机（谨慎动机）**：为应对意外支出和不确定性而持有货币。也主要取决于收入水平，与收入正相关。与交易动机合称 $L_1(Y)$。

3. **投机动机**：为抓住有利的债券买卖时机而持有货币。取决于利率水平，利率越低，持有货币的机会成本越小，投机动机货币需求越大。$L_2 = -hr$。

总货币需求：$L = L_1 + L_2 = kY - hr$。

**5、凯恩斯的货币需求理论与旧传统的货币需求理论有什么不同？**

**旧传统理论（古典货币数量论）**：

- 核心观点：货币只是交易媒介，人们持有货币仅为了交易。货币需求与收入成正比，与利率无关。
- 费雪方程式：$MV = PY$。货币流通速度 $V$ 稳定。
- 剑桥方程式：$M = kPY$。$k$ 为常数。
- LM 曲线含义：垂直（$h = 0$）。

**凯恩斯货币需求理论**：

- 核心观点：货币不仅是交易媒介，还是价值储藏手段。人们持有货币有交易、预防、投机三种动机。
- 货币需求不仅取决于收入，还取决于利率。投机动机使货币需求与利率负相关。
- 货币流通速度不稳定，受利率影响。
- LM 曲线向右上方倾斜，且存在"流动性陷阱"（$h \to \infty$，LM 水平段）。

**根本分歧**：古典理论认为货币只是"面纱"，不影响真实经济（货币中性）；凯恩斯认为货币需求受利率影响，货币供给变动可以通过利率影响投资和产出（货币非中性）。

## 四、计算题

**1、** 假定某经济中有 $C=100+0.75Y_d$，$I=125-600r$，$G=50$，$T=20+0.2Y$，转移支付 $Tr=0$，求：

**(1) IS曲线的方程**

可支配收入：$Y_d = Y - T + Tr = Y - 20 - 0.2Y = 0.8Y - 20$。

产品市场均衡 $Y = C + I + G$：

$Y = 100 + 0.75(0.8Y - 20) + 125 - 600r + 50$
$Y = 100 + 0.6Y - 15 + 125 - 600r + 50$
$Y = 0.6Y + 260 - 600r$
$0.4Y = 260 - 600r$

IS 曲线方程：$Y = 650 - 1500r$。

**(2) 当 $r=0.15$ 时，$Y$ 是多少？如果充分就业收入 $Y_f=465$，假设利率保持不变，应增加多少政府支出才能实现充分就业？**

$r = 0.15$ 时：$Y = 650 - 1500 \times 0.15 = 650 - 225 = 425$。

产出缺口：$\Delta Y = 465 - 425 = 40$。

政府购买乘数（考虑比例税）：$k_g = \frac{1}{1 - b(1-t)} = \frac{1}{1 - 0.75 \times 0.8} = \frac{1}{0.4} = 2.5$。

需增加政府支出：$\Delta G = \frac{\Delta Y}{k_g} = \frac{40}{2.5} = 16$。

**(3) 当增加政府支出 $\Delta G=10$ 时，收入增加多少？**

$\Delta Y = k_g \times \Delta G = 2.5 \times 10 = 25$。

---

**2、** 假定名义货币供给量用 $M$ 表示，价格水平 $P=1$，货币需求用 $L=kY-hr$ 表示，求：

**(1) LM曲线的代数表达式，找出LM曲线的斜率代数表达式。**

货币市场均衡：$M = L = kY - hr$。

LM 曲线：$r = \frac{k}{h}Y - \frac{M}{h}$。

LM 曲线斜率为 $\frac{k}{h}$。

**(2) 找出 $k=0.2$, $h=10$；$k=0.2$, $h=20$；$k=0.1$, $h=10$ 时，LM 曲线斜率的值。**

- $k=0.2$，$h=10$：斜率 $= \frac{0.2}{10} = 0.02$
- $k=0.2$，$h=20$：斜率 $= \frac{0.2}{20} = 0.01$
- $k=0.1$，$h=10$：斜率 $= \frac{0.1}{10} = 0.01$

**(3) 当 $k$ 变小时，LM曲线的斜率如何变化？$h$ 增大时，LM曲线的斜率如何变化？**

斜率 $= \frac{k}{h}$。

- $k$ 变小 → 斜率变小，LM 更平坦。$k$ 越小，收入增加带来的交易货币需求增量越小，利率上升幅度越小。
- $h$ 增大 → 斜率变小，LM 更平坦。$h$ 越大，利率小幅上升就能释放大量投机货币，利率对收入变动的反应越弱。

**3、** 假定某经济中消费函数为 $C=0.8(1-t)Y$，税率 $t=0.25$，投资函数为 $I=900-50r$，政府购买 $G=800$，货币需求为 $L=0.25Y+200-62.5r$，实际货币供给为 $M=700$。求：

**(1) IS曲线方程。**

$C = 0.8(1-0.25)Y = 0.6Y$。

$Y = C + I + G = 0.6Y + 900 - 50r + 800 = 0.6Y + 1700 - 50r$

$0.4Y = 1700 - 50r$

IS 曲线：$Y = 4250 - 125r$。

**(2) LM曲线方程。**

货币市场均衡：$700 = 0.25Y + 200 - 62.5r$

$500 = 0.25Y - 62.5r$

$0.25Y = 500 + 62.5r$

LM 曲线：$Y = 2000 + 250r$。

**(3) 两个市场同时均衡时的利率和收入。**

联立 IS 和 LM：

$4250 - 125r = 2000 + 250r$
$2250 = 375r$
$r = 6$。

代入 IS：$Y = 4250 - 125 \times 6 = 4250 - 750 = 3500$。

代入 LM 验证：$Y = 2000 + 250 \times 6 = 2000 + 1500 = 3500$。✓

均衡利率 $r = 6\%$，均衡收入 $Y = 3500$。

**4、** 已知消费函数为 $C=130+0.6Y$，投资函数为 $I=750-2000r$，设政府购买支出 $G=750$。试计算：

**(1) 若投资函数变为 $I=750-3000r$，推导投资函数变化前和变化后的IS曲线并比较斜率。**

**变化前**（$d = 2000$）：

$Y = 130 + 0.6Y + 750 - 2000r + 750$
$Y = 0.6Y + 1630 - 2000r$
$0.4Y = 1630 - 2000r$
$Y = 4075 - 5000r$。

斜率（绝对值）为 $5000$。

**变化后**（$d = 3000$）：

$Y = 130 + 0.6Y + 750 - 3000r + 750$
$Y = 0.6Y + 1630 - 3000r$
$0.4Y = 1630 - 3000r$
$Y = 4075 - 7500r$。

斜率（绝对值）为 $7500$。

**比较**：变化后 IS 曲线斜率的绝对值更大（从 5000 增加到 7500），但 $d$ 增大使得投资对利率更敏感，给定利率变动引起的投资变动更大，因此 IS 曲线更**平坦**。注意：IS 斜率为负，绝对值越大表示曲线越平。

**(2) 增加政府购买支出时，比较投资函数在变化前后哪种情况的收入变化大。**

政府购买乘数均为 $k_g = \frac{1}{1-0.6} = 2.5$，IS 水平右移幅度相同。

但 $d$ 较小（变化前 $d=2000$）时 IS 更陡峭，扩张财政导致利率上升更多，挤出效应更大，实际收入增加较小。

$d$ 较大（变化后 $d=3000$）时 IS 更平坦，利率上升幅度较小，挤出效应较小。

因此**变化后**（$d=3000$，IS 更平坦）增加政府购买的收入变化更大。

**(3) 增加货币供给时，比较投资函数在变化前后哪种情况对收入的影响大。**

货币供给增加使 LM 右移，利率下降。投资对利率越敏感（$d$ 越大），同样的利率下降带来的投资增加越多，收入增加越大。

变化后 $d=3000$ 时投资对利率更敏感，货币政策效果更强。

因此**变化后**（$d=3000$）增加货币供给对收入的影响更大。
