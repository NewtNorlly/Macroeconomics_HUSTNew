# 作业四：国民收入决定理论 答案

**第2章 国民收入决定理论**

---

## 一、选择题

1、凯恩斯主义关于均衡国民收入决定的基本原理是（）

- A.总供给水平决定均衡国民收入水平
- B.总需求水平决定均衡国民收入水平 ✅
- C.消费水平决定均衡国民收入水平
- D.总供给水平和总需求水平同时决定均衡

凯恩斯交叉图的核心是总需求决定均衡产出。在简单国民收入决定模型中，均衡条件为 $Y = AD = C + I + G$，产出由总需求水平决定。总供给被动适应总需求，这是凯恩斯理论的基本逻辑。

2、当消费函数为 $C = a + by$， $a > 0$， $0 < b < 1$ 时，这表明，平均消费倾向()。

- A.大于边际消费倾向 ✅
- B.小于边际消费倾向
- C.等于边际消费倾向
- D.以上三种情况都有可能

$APC = \frac{C}{Y} = \frac{a}{Y} + b$，$MPC = b$。由于 $a > 0$，故 $\frac{a}{Y} > 0$，因此 $APC = \frac{a}{Y} + b > b = MPC$。随着收入增加，$\frac{a}{Y}$ 递减，APC 逐渐趋近于 MPC。

3、假设储蓄函数的形式为 $S = -400 + 0.25Y_d$，边际所得税率为 $t = 0.2$。如果均衡水平的收入增加1000，那么消费会变化()。

- A.250
- B.400
- C.600 ✅
- D.750

由 $S = -400 + 0.25Y_d$ 得 $MPS = 0.25$，故 $MPC = 0.75$。
收入增加 $\Delta Y = 1000$，可支配收入增量 $\Delta Y_d = (1 - t)\Delta Y = 0.8 \times 1000 = 800$。
消费变化 $\Delta C = MPC \times \Delta Y_d = 0.75 \times 800 = 600$。

4、如果边际消费倾向为1.3，那么，边际储蓄倾向为（ ）。

- A.-0.3 ✅
- B.0
- C.0.3
- D.0.7

$MPC + MPS = 1$，故 $MPS = 1 - 1.3 = -0.3$。MPC > 1 意味着消费增量超过收入增量，在理论上对应负储蓄。

5、下列说法正确的是（ ）

- A.MPC与MPS成正比
- B.MPC+APC=1
- C.MPC+MPS=APC+APS ✅
- D.MPC+MPS>APC+APS

$MPC + MPS = 1$，$APC + APS = 1$，因此 $MPC + MPS = APC + APS$。

6、（ ）将导致经济有最大增长。

- A.政府增加购买50亿元商品和劳务 ✅
- B.政府增加50亿元税收然后将其全部用于购买商品和劳务
- C.减少50亿元税收
- D.政府增加购买50亿元，其中20亿元由增加的税收支付

比较各项对国民收入的净效应（设MPC = b）：
A：$\Delta Y = \frac{50}{1-b}$，效应最大。
B：$\Delta G = 50$，$\Delta T = 50$，$\Delta Y = \frac{50}{1-b} - \frac{50b}{1-b} = 50$。
C：$\Delta Y = \frac{50b}{1-b} < \frac{50}{1-b}$。
D：$\Delta G = 50$，$\Delta T = 20$，$\Delta Y = \frac{50}{1-b} - \frac{20b}{1-b} < \frac{50}{1-b}$。

7、如果边际消费倾向为0.8，政府购买支出增加200亿元，则可以使国民收入（ ）

- A.增加 200亿元
- B.减少 200 亿元
- C.增加 1000 亿元 ✅
- D.减少 1000 亿元

政府购买乘数 $k_g = \frac{1}{1-0.8} = 5$。$\Delta Y = k_g \times \Delta G = 5 \times 200 = 1000$ 亿元。

8、若其他情况不变，所得税的征收将会使得（ ）。

- A.支出乘数和税收乘数都变大
- B.支出乘数增大，税收乘数变小
- C.支出乘数和税收乘数都变小 ✅
- D.支出乘数变小，税收乘数增大

征收比例所得税后，乘数公式中的边际消费倾向调整为 $b(1-t)$，支出乘数降为 $\frac{1}{1-b(1-t)}$，小于无税时的 $\frac{1}{1-b}$。税收乘数也相应缩小。

9、就定量税而言，税收乘数和转移支付乘数的唯一区别是（ ）。

- A.前者总比后者小1
- B.前者为负，后者为正 ✅
- C.后者为负，前者为正
- D.二者互为倒数

定量税下：税收乘数 $k_T = -\frac{b}{1-b}$，转移支付乘数 $k_{tr} = \frac{b}{1-b}$。二者绝对值相等，符号相反。

10、如果边际储蓄倾向为0.3，投资支出增加60亿元，可以预期，这将导致均衡国民收入增加（ ）

- A.20亿元
- B.60亿元
- C.180亿元
- D.200亿元 ✅

$MPS = 0.3$，故 $MPC = 0.7$。投资乘数 $k_i = \frac{1}{MPS} = \frac{1}{0.3} \approx 3.33$。$\Delta Y = \frac{60}{0.3} = 200$ 亿元。

11、假设边际消费倾向为0.8，如果政府购买支出增加100亿元，同时税收增加100亿元，则会使国民收入（ ）

- A.变大 ✅
- B.变小
- C.不变
- D.不确定

平衡预算乘数 $k_b = 1$。$\Delta G = \Delta T = 100$，$\Delta Y = 1 \times 100 = 100$ 亿元，国民收入增加。

12、假如某国目前的均衡国民收入为5500亿元。若政府要把国民收入水平提高到6000亿元，在边际消费倾向等于90%的条件下，应增加政府支出（ ）亿元。

- A.50 ✅
- B.450
- C.500
- D.540

$\Delta Y = 6000 - 5500 = 500$。$MPC = 0.9$，$k_g = \frac{1}{1-0.9} = 10$。$\Delta G = \frac{500}{10} = 50$ 亿元。

13、如果投资增加150亿元，边际消费倾向为0.8，那么收入水平将增加（ ）

- A.190亿元并保持在这一水平
- B.750亿元之后又回到最初水平
- C.750亿元并保持在这一水平 ✅
- D.150亿元，最后又回到原有水平

投资乘数 $k_i = \frac{1}{1-0.8} = 5$。$\Delta Y = 5 \times 150 = 750$ 亿元。乘数作用完成后，收入稳定在新的均衡水平。

14、在三部门经济中，充分就业的国民收入是2000亿元，消费支出在充分就业的国民收入水平上是1700亿元，I和G的和在任何国民收入水平上都是200亿元，MPC为 $\frac{3}{4}$，则均衡国民收入等于（ ）

- A.2000亿元
- B.1900亿元
- C.1600亿元 ✅
- D.1700亿元

由 $C = a + bY$，在 $Y = 2000$ 时 $C = 1700$，$b = \frac{3}{4}$：
$1700 = a + \frac{3}{4} \times 2000 = a + 1500$，得 $a = 200$。
均衡收入 $Y = \frac{a + I + G}{1-b} = \frac{200 + 200}{1-\frac{3}{4}} = \frac{400}{0.25} = 1600$ 亿元。

15、根据持久收入消费函数理论，（ ）之间存在高度的相关性和稳定的函数关系。

- A.暂时收入与暂时消费
- B.持久收入与持久消费 ✅
- C.暂时收入与持久消费
- D.持久收入与暂时消费

弗里德曼的持久收入假说认为，消费主要取决于持久收入而非暂时收入。持久消费与持久收入之间存在稳定的比例关系。

16、根据生命周期的消费理论，退休期人们的生活水平将会（ ）

- A.下降
- B.提高
- C.不变 ✅
- D.不确定

莫迪利安尼的生命周期理论认为，理性消费者会根据一生总收入来平滑各期消费。退休期虽然收入减少，但通过动用工作期的储蓄，可以维持与工作期大致相同的消费水平。

## 二、名词解释

**1、边际消费倾向**

每增加一单位可支配收入所增加的消费量，即 $MPC = \frac{\Delta C}{\Delta Y_d}$。MPC 是消费函数的斜率，取值在 0 到 1 之间。凯恩斯认为边际消费倾向随收入增加而递减。

**2、政府购买乘数**

政府购买支出变动所引起的国民收入变动的倍数，$k_g = \frac{\Delta Y}{\Delta G}$。在两部门定量税条件下，$k_g = \frac{1}{1-b}$，其中 $b$ 为边际消费倾向。乘数大于 1，体现了政府购买对国民收入的放大效应。

**3、平衡预算乘数**

政府税收和购买支出以相等数量增减时，国民收入变动对政府收支变动的比率。在定量税条件下，平衡预算乘数 $k_b = 1$，即政府同时等量增加购买和税收，国民收入增加额等于政府购买增加额。

**4、投资乘数**

投资变动所引起的国民收入变动的倍数，$k_i = \frac{\Delta Y}{\Delta I}$。在两部门经济中 $k_i = \frac{1}{1-b} = \frac{1}{MPS}$。投资增加会通过连锁的消费支出扩张，使国民收入成倍增长。

**5、政府转移支付乘数**

政府转移支付变动所引起的国民收入变动的倍数，$k_{tr} = \frac{\Delta Y}{\Delta Tr}$。在定量税条件下 $k_{tr} = \frac{b}{1-b}$。其绝对值小于政府购买乘数，因为转移支付需先转化为可支配收入，其中只有 $b$ 比例用于消费。

**6、棘轮效应**

杜森贝利提出的相对收入消费理论概念。消费具有不可逆性：收入提高时消费随之增加，但收入下降时，消费者不愿削减消费，消费并不按相同比例下降。"由俭入奢易，由奢入俭难"。

**7、攀比效应**

又称"示范效应"，也是相对收入消费理论的内容。消费者的消费行为不仅取决于自身收入，还受周围人消费水平的影响。即使自身收入未增长，为追赶他人的消费水平，也可能增加消费、减少储蓄。

## 三、简答题

**1、为什么边际消费倾向和平均消费倾向都总是大于零而小于1？**

**边际消费倾向大于零小于1：**

- 大于零：收入增加必然带来消费的增加，这是人类基本消费规律。完全不增加消费不符合实际。
- 小于1：收入增量不会全部用于消费，总有一部分用于储蓄。凯恩斯的基本心理规律是"消费的增加不及收入增加的多"。

**平均消费倾向大于零小于1：**

- 大于零：只要收入为正，消费就不可能为零或为负，基本生存消费必不可少。
- 小于1：通常情况下消费小于收入，存在正储蓄。当 $a > 0$ 时，$APC = \frac{a}{Y} + MPC > MPC$，随收入增加而递减，始终大于 MPC 但趋近于 MPC。

**2、凯恩斯消费理论的主要观点**

**核心观点：消费取决于当期绝对收入。**

具体展开为三条基本心理规律：

1. **边际消费倾向递减规律**：随着收入增加，消费也增加，但消费增量在收入增量中所占比例递减，即 MPC 递减。这意味着富人的 MPC 低于穷人。

2. **消费与收入的函数关系**：$C = a + bY$。其中 $a$ 为自发性消费（维持基本生活所需），$bY$ 为引致消费（随收入变化的部分），$b$ 为边际消费倾向，$0 < b < 1$。

3. **平均消费倾向递减**：$APC = \frac{C}{Y} = \frac{a}{Y} + b$，随收入增加而递减。由于 $a > 0$，$APC > MPC$。

政策含义：由于 MPC 递减，社会有效需求可能不足，需要政府通过财政政策刺激消费和投资。

## 四、计算题

**1、** 假设某经济社会的储蓄函数为 $s = -1600 + 0.25y$，投资从 $i = 400$ 增加到 $i = 600$ 时，均衡国民收入增加多少？

**解：**

由储蓄函数 $s = -1600 + 0.25y$ 知，$MPS = 0.25$，故 $MPC = 0.75$。

均衡条件：$i = s$，即 $i = -1600 + 0.25y$。

投资乘数：$k_i = \frac{1}{MPS} = \frac{1}{0.25} = 4$。

投资增量：$\Delta i = 600 - 400 = 200$。

均衡国民收入增量：$\Delta y = k_i \times \Delta i = 4 \times 200 = 800$。

---

**2、** 假定某经济社会的消费函数为 $C = 100 + 0.8Y$（可支配收入），投资支出为 $I = 50$，政府购买支出 $G = 200$，政府转移支付 $Tr = 62.5$，税收 $T = 250$（单位：亿元），试求：

**（1）均衡的国民收入**

可支配收入 $Y_d = Y - T + Tr = Y - 250 + 62.5 = Y - 187.5$。

总需求 $AD = C + I + G = 100 + 0.8(Y - 187.5) + 50 + 200$
$= 350 + 0.8Y - 150 = 0.8Y + 200$

均衡条件 $Y = AD$：
$Y = 0.8Y + 200$
$0.2Y = 200$
$Y = 1000$ 亿元。

**（2）投资乘数、政府购买乘数、税收乘数、转移支付乘数以及平衡预算乘数**

$b = 0.8$。

- 投资乘数 $k_i = \frac{1}{1-b} = \frac{1}{0.2} = 5$
- 政府购买乘数 $k_g = \frac{1}{1-b} = 5$
- 税收乘数 $k_T = -\frac{b}{1-b} = -\frac{0.8}{0.2} = -4$
- 转移支付乘数 $k_{tr} = \frac{b}{1-b} = \frac{0.8}{0.2} = 4$
- 平衡预算乘数 $k_b = 1$

---

**3、** 假设某经济社会的消费函数为 $C = 100 + 0.8Y$，投资为 $50$（单位：10亿元）。求：

**(1) 均衡收入、消费和储蓄。**

均衡条件 $Y = C + I = 100 + 0.8Y + 50$：
$Y - 0.8Y = 150$
$Y = \frac{150}{0.2} = 750$（10亿元）。

消费 $C = 100 + 0.8 \times 750 = 700$（10亿元）。

储蓄 $S = Y - C = 750 - 700 = 50$（10亿元），恰好等于投资。

**(2) 若投资增至 $100$，求增加的国民收入。**

投资乘数 $k_i = \frac{1}{1-0.8} = 5$。

新均衡收入 $Y' = \frac{100 + 100}{0.2} = 1000$（10亿元）。

收入增量 $\Delta Y = 1000 - 750 = 250$（10亿元），恰好等于 $k_i \times \Delta I = 5 \times 50 = 250$。

**(3) 若消费函数为 $C = 100 + 0.9Y$，投资仍为 $50$，收入和储蓄各为多少？投资增至 $100$ 时收入增加多少？**

当 $b = 0.9$，$I = 50$：
$Y = \frac{100 + 50}{1 - 0.9} = \frac{150}{0.1} = 1500$（10亿元）。

$C = 100 + 0.9 \times 1500 = 1450$（10亿元）。

$S = Y - C = 1500 - 1450 = 50$（10亿元），仍等于投资。

投资增至 $100$：
$Y' = \frac{100 + 100}{0.1} = 2000$（10亿元）。
$\Delta Y = 2000 - 1500 = 500$（10亿元）。

**(4) 消费函数变化后，投资乘数有什么变化？**

原投资乘数 $k_i = \frac{1}{1-0.8} = 5$。
新投资乘数 $k_i' = \frac{1}{1-0.9} = 10$。

投资乘数从 5 增大到 10。边际消费倾向越大，乘数越大，投资变动对国民收入的放大效应越强。
